## A small shared capability

The following is a **trusted compiled host module**, not an importable `.tfi` or an arbitrary-code loader. Its import paths are shown relative to this documentation directory; adjust them to the source module's actual location. It registers a local calculation, changes its implementation and disposes its resources. Both language versions are exercised against the real registry by the documentation regression.

```ts
import { CapabilityError, type ToolDefinition } from '../../src/ai-capabilities/contracts.ts';
import type { CapabilityOwner } from '../../src/ai-capabilities/registry.ts';

export function mountScaleTool(owner: CapabilityOwner) {
  let version = 1;
  const definition = (factor: number): ToolDefinition => ({
    id: `user.${owner.id}.scale`, version, title: 'Scale a number',
    description: `Multiply the input by ${factor} locally.`,
    effect: 'read', scope: 'app',
    inputSchema: {
      type: 'object', properties: { value: { type: 'number' } },
      required: ['value'], additionalProperties: false,
    },
    outputSchema: {
      type: 'object', properties: { value: { type: 'number' } },
      required: ['value'], additionalProperties: false,
    },
    run(input, execution) {
      execution.checkpoint();
      const value = (input as { value: number }).value * factor;
      if (!Number.isFinite(value)) throw new CapabilityError('numeric_overflow');
      return { value };
    },
  });
  owner.register(definition(2));
  return {
    async updateFactor(factor: number) {
      if (!Number.isFinite(factor)) throw new CapabilityError('invalid_request');
      version++;
      await owner.update(definition(factor));
    },
    async close() { await owner.dispose(); },
  };
}
```

Create an owner through the application's capability-registration entry, keep the module handle, and await `close()` on removal. `registry.createOwner('example')` creates an owner for direct registry use. The module does not access files, market data or credentials. A wrapper for untrusted code must delegate to an isolated runtime instead of evaluating code in the main page.

## Registration and writes

Tool definitions require `id/version/description/effect/inputSchema/outputSchema/run`. Provide a user-readable `title`. Scope is currently `app` or `chart`; effect is `read`, `propose` or `write`. Do not mislabel a mutating operation as read.

Use the existing `prepare` or `prepareAsync` transaction contract for writes, not both. Preserve commit, compensation and lease cleanup. `source/ownerId/registrationRevision/wireName` are generated by the registry; supplied fields cannot impersonate built-in tools. Business `version` is separate from `protocolVersion`.

Owners support `register`, `update`, `unregister`, `describe` and `dispose`. Updates publish a new registration identity and cancel retired work. Await update/unregister/dispose until handlers and compensation actually finish. A canceled request still running native IO is not released capacity. Use `signal/checkpoint`, session identity for shared results and registration lifetime for implementation-owned resources.

The built-in assistant refreshes tools before model requests. External MCP receives list-change notifications. Dynamic wire names and revision metadata come from discovery; no model-specific hardcoded branch is necessary.

## Validate a source change

Read [AGENTS.md](../../AGENTS.md), inspect Git status and preserve unrelated work. Add focused regression coverage for lifecycle/cancellation, malformed inputs and relevant existing behavior. Run documentation tests for either-language edits; run the related contract suites and a frontend build for TypeScript changes. Run Cargo tests for Rust changes. Network/desktop verification is a separate claim from deterministic tests.

Do not introduce a hosted official database, marketplace approval requirement or extra provider as an incidental part of fixing a core contract. Keep user-owned extensions possible with only necessary safety and resource boundaries. Licensing and third-party provenance must be checked before redistributing a derivative build.
