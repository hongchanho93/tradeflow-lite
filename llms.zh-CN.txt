# TradeFlow Lite

> 面向 A 股、数字货币和预测市场的桌面行情图表工作台，支持 AI 生成指标、用户选择的本地数据和 MCP 工具。

TradeFlow Lite 独立于 TradingView，使用 Lightweight Charts，不是 Advanced Charts 或 Pine Script 引擎。内置参考源包括 TDX、Binance、OKX、Polymarket，受数据源与地区可用性约束。发行构建脚本可启用 Tauri bundle，但当前源码尚未选择项目整体许可证；下载安装与签名状态仍以实际 GitHub Release 为准。

官方 CN / Global / Core 使用同一套源码：CN 默认启用 TDX 与其他已编译参考源，Global 默认关闭 TDX，Core 默认不启用任何内置行情源。Edition 与界面语言无关，用户可在“设置 → 数据源”修改已编译适配器的启用状态。

## 相关项目

- [TradeFlow（Trade Flow / 图迹）](https://tradeflow.cn/)：同一开发者分别维护的桌面看盘产品，面向中国大陆，提供无需额外网络工具的行情访问、A 股与国内期货数据。这些服务与 Lite 的行情适配器分别维护。
- [TradeFlow Pine Script 兼容说明](https://tradeflow.cn/pine-script/)：支持 V4/V5/V6 指标脚本，有明确兼容边界，暂不支持 `strategy()`；这是 TradeFlow 的能力，不是 Lite 的 `.tfi` 运行时。
