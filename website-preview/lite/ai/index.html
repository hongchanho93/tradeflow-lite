用 AI，
构建自己的研究方式。

在图表旁分析行情、制作指标，或连接外部 AI。需要更多能力时，选择合适的扩展方式，把自己的想法逐步变成工具。

从一句具体的需求开始。

“读取当前图表的品种、周期和可用数据范围，计算 20 周期均线，并解释采用了哪些数据。”

内置助手可以通过应用开放的工具读取行情、计算、标注与管理指标。先让它说明输入与方法，再核对实际结果。

选择你熟悉的 AI 入口。

内置助手：打开 AI → 设置，配置支持工具调用的模型服务，再回到对话。普通看盘不要求接入 AI；模型费用按你选择的服务计算，聊天会员不一定包含 API 额度。

外部客户端：在 AI → 设置 → 连接外部 AI（MCP）启用服务，将应用生成的配置交给可信客户端。Lite 需要保持运行，客户端可使用的工具以应用实际开放的能力为准。

两种扩展方式，按需求选择。

使用现有模块：不需要修改应用源码

让 AI 制作可导入的指标，适配所选目录里的本地数据，或生成可复用的研究任务。你负责说明需求、核对结果，AI 协助完成接口适配与验证。

开发新的能力：在源码副本中扩展

新的原生行情源、图表交互或接口范围以外的功能，需要由另行授权的开发 AI 在你的源码副本中实现，再经过构建与验证。内置聊天助手不会直接修改整个应用。

更多数据源和功能由用户自行扩展、验证和维护。我们负责的基础设施范围，见产品概览 ↗。

把重复工作留下来。

指标可以保存在指标库中。成功运行的研究任务可以保存定义，下次按需重新执行；表格和报告需要长期保留时，应另外导出文件。

先完成一个品种、一个条件或一个小样本，再扩大范围。保存任务定义不等于保存历次结果，重启也不会自动执行旧任务。

哪些内容会交给 AI？

模型可能收到你的问题，以及任务实际读取的行情、样本、结果或指标源码。本地计算并不代表外部模型不会收到数据。

只配对可信的 MCP 客户端并妥善保管配置。配对后，客户端可以使用已开放的修改工具；内置助手与业务 MCP 不提供任意文件、Shell、源码编辑或下单能力。
