# Trade Flow 图表界面 · CSS / SVG 提取

按你两张截图里**看得见的部分**扒的。图标想直接看长什么样，打开 `图标总览.html`（206 个图标一屏排开，图下面就是文件名）。

一句话说明现状：截图里这套界面是**两层叠出来的**——
底下是 TradingView charting_library 编译好的原生样式（类名带哈希，如 `.wrapper-FNeSdxed`，改不动也不该改），
上面是本项目用 JS 注入的一层皮肤（`--tv-custom-*` 变量 + `!important` 覆盖），把 TV 默认的蓝白改成了 `#131722` 暗色机身、加上了右侧竖排标签和底部横排标签。

## 几个要知道的点

1. **绘图工具图标有原名，工具栏图标没有。** `绘图工具图标/` 那 87 个 webpack 里保留了 `lineToolsIcons` 映射表，所以文件名就是 TV 的原始标识（`LineToolFibRetracement` 之类）。顶部/左侧那些图标在压缩时名字被丢掉了，只剩模块号，所以按 `module-<数字>.svg` 命名 —— 认图请开 `图标总览.html`。

2. **自定义层是 JS 注入的，不是静态 CSS 文件。** 这几份 `.css` 是我从 `index.html` 里的 JS 字符串数组还原出来的，改它们**不会生效**。真正要改得回 `charting_library-master-main/index.html`，每份文件头部注释都写了原始行号和函数名（如 `injectTradingViewIframeThemeStyle()` 在 19162–19349 行）。

3. **TV 原生层的类名带哈希**，如 `.wrapper-FNeSdxed`，升级 charting_library 后会变。项目里覆盖它们用的是属性选择器 `[class*='header-toolbar']` 这种写法，就是为了扛住哈希变化。

4. 图例下面那个红蓝的 **63.42 卖出 / 63.42 买入** 是 TV 自带的交易面板买卖按钮，样式在主壳那份 23308 里，不是本项目画的。

5. `02-TV原生层/原始压缩/` 放了未格式化的原文件，对照行号用；格式化版本只是给人看的，内容一字不差。
